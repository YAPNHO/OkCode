# OkCode 第十阶段补充：Skill 斜杠命令 Spec

## 背景

第十阶段已实现 Skill 的发现、按需加载和 `/skill` 列表命令，但普通 Skill 不能直接通过斜杠命令使用。用户在 `/skill` 中看到 `commit` 或 `test` 后，应能用 `/commit`、`/test` 明确表达“使用该 Skill”。

原有的三级来源覆盖规则继续有效：同名 Skill 按项目目录高于用户目录高于内置目录选择最终生效版本。斜杠命令只针对最终生效的 Skill 注册，不为被覆盖版本注册额外命令。

现有内置 `/review` 命令保留。内置 `review` Skill 删除，避免它与 `/review` 的命令名冲突；后续任何最终生效 Skill 若与内置斜杠命令重名，启动必须失败并给出可诊断错误。

## 目标

- 让有效 Skill 在斜杠命令中可发现、可补全、可直接使用。
- 保持 `load_skill` 是完整 SOP 的唯一激活路径，不能因斜杠命令重新引入启动期 SOP 注入。
- 在启动和热更新时可靠处理命令名称冲突，不产生部分注册状态。

## 功能需求

- F1：启动完成 Skill 发现、来源覆盖和白名单校验后，系统为每个最终生效且不冲突的 Skill 注册同名斜杠命令。例如 `/skill` 列表中有 `commit`、`test` 时，命令补全和 `/help` 中也分别有 `/commit`、`/test`。
- F2：用户输入 `/<skill> [任务文本]` 时，系统将其作为“使用指定 Skill 完成任务”的正常 Agent 请求继续执行；Agent 仍通过系统级 `load_skill` 加载完整 SOP，再按该 Skill 的 shared 或 isolated 模式完成工作。任务文本为空时，命令仍表示使用该 Skill，并由 Agent 根据当前工作区和 Skill SOP 执行。
- F3：动态 Skill 命令必须保留 Skill 名称、来源和一句话说明，以便 `/help` 和补全显示；启动期提示词仍只暴露名称和说明，不能暴露完整 SOP。
- F4：同名 Skill 的发现继续按 `PROJECT > USER > BUILTIN` 覆盖。只有覆盖后的有效 Skill 参与命令注册；同一来源的同名 Skill 仍是启动失败。
- F5：最终生效的 Skill 名称若与任意内置斜杠命令、另一有效 Skill 命令或其别名冲突，启动失败。错误必须包含冲突的命令名、Skill 来源路径和已有命令所有者。
- F6：移除内置 `review` Skill；已有 `/review` 内置命令继续保留其原有行为。项目或用户目录中新出现的有效 `review` Skill 因与内置 `/review` 冲突而启动失败。
- F7：执行 `/skill` 以及通过 `load_skill` 刷新目录时，系统重新计算有效 Skill 和动态命令。新增或修改后可注册的命令在刷新后可用；已删除或解析失败的 Skill 命令在刷新后移除；激活快照不因刷新改变。
- F8：热更新发现命令冲突时，不替换当前可用的动态命令注册表；`/skill` 显示具体错误，下一次进程启动仍以该冲突作为启动失败处理。

## 非功能需求

- N1：动态注册、替换或移除命令必须原子完成，不能使终端补全、命令分发和 `/help` 看到不同版本的命令集合。
- N2：冲突检测、动态命令刷新和 `/skill` 列表不得读取或显示完整 SOP。
- N3：原有 `/exit`、`/clear`、`/plan`、`/do`、`/review` 等内置命令行为不能回归。
- N4：命令处理仍复用现有 Agent、工具白名单、权限确认和会话原子提交边界。

## 不做的事

- 不为被覆盖的 Skill 注册别名或多版本命令。
- 不允许动态 Skill 覆盖、重定义或隐藏内置斜杠命令。
- 不增加 Skill 市场、分发、版本管理或命令参数的独立 schema。
- 不改变 `load_skill` 的系统级工具地位，也不将完整 SOP 写入普通命令历史之外的启动上下文。

## 验收标准

- AC1：内置有效 `commit`、`test` Skill 在 `/skill`、`/help` 和补全中均可见对应的 `/commit`、`/test`；输入这些命令会进入指定 Skill 的加载和执行流程。
- AC2：启动期提示词和 `/skill` 输出只含 Skill 名称、来源、说明和状态，不含完整 SOP；命令触发后的下一次 Agent 请求才通过 `load_skill` 获得完整 SOP。
- AC3：项目、用户、内置三级同名 Skill 仍只保留优先级最高版本，并只注册该版本的一个命令。
- AC4：同一来源同名 Skill、有效 Skill 与内置命令冲突、有效 Skill 与动态 Skill 命令冲突均在启动期失败，错误可定位到命令名和相关路径。
- AC5：内置 `review` Skill 不再出现在 `/skill`；既有 `/review` 命令仍可分发并保持既有行为；外部 `review` Skill 会因命令冲突导致启动失败。
- AC6：刷新后新增 Skill 命令可被补全和分发，已删除或解析失败 Skill 的命令被移除；已激活 Skill 继续使用原快照。
- AC7：全量测试、格式检查、静态检查和 Git 空白检查通过。
